# DOMANDO RUSH Ver.6.0 — WORLD FESTIVAL

**4ジャンルのゲームと、自由に旅するシングルプレイの冒険世界。**

> Ver.5.0からの改良版です。キャラクター・画面・ルールはオリジナル。人気作品から学んだ操作性やゲームのテンポを参考にしていますが、キャラクター・画像・音楽・コードの転載はありません。

## 何が変わった？

### ワールド
- 4320×3024の広いワールドとカメラ追従を維持（森、山、海岸、村、洞窟、船着き場、島、宝箱、NPC）。
- 地形境界のなめらかさ、温かい日差し、漂う光の演出、UIのコントラストを改良。
- **Qキーまたは画面右上の「遊びを選ぶ」**で、遠くの目的地まで歩かなくても4ゲームに直接挑戦できます。
- ワールドの探索・宝箱・施設は引き続き利用できます。

### 4つのゲーム（すべて別のジャンル）
1. **虹嵐の森 — サバイバル**：自動魔法、攻撃強化、選択式レベルアップ、周囲を回る星球、範囲魔法、ダッシュ、虹ストーム、ボス、3段階の難易度。
2. **風渡りの塔 — ジャンプアクション**：空中ダッシュ、2段ジャンプの育成、入力猶予、落下時のチェックポイント、星の収集、3段階の難易度。
3. **月影の神殿 — 戦略RPG**：相手の次の行動を表示、コマンド選択、集中の管理、結界BREAK、3章の連戦、回復と防御。
4. **光環の工房 — パズル**：8種類の回路を回して光をつなぐ。ヒント、取り消し、クリア評価。

### やり込み
- ゲームごとの最高記録、難易度ごとの星評価、クリア回数。
- 工房で最大4段階のHP・ジャンプ・集中の強化。
- 5色のマントの購入・着替え。購入後は自由に切り替え。
- 宝箱探し、洞窟探索、全4モード制覇報酬、冒険記録。
- 報酬はゲーム内コインのみ。課金や広告、リアルマネー、ランダム購入はありません。

## 遊び方

### PC
- ワールド移動：WASD / 矢印キー。Shiftで走る。
- 調べる・建物に入る：E / Enter。
- ゲーム選択：Q（左上の画面メニューからも可能）。
- 地図：M。記録：J。
- サバイバル：WASD/矢印で移動、攻撃は自動。Shiftでダッシュ。虹ゲージ100%で Space の虹ストーム。レベルアップ画面は数字1〜3でも選択可。
- ジャンプアクション：左右移動、Spaceでジャンプ、Shiftで空中ダッシュ。
- 戦略RPG：1〜4または画面上のコマンドボタン。
- パズル：回転したいパネルをクリック。左下で取り消し、右下でヒント。
- Escapeで一時停止・戻る。

### スマホ
- 横画面推奨。画面下の方向ボタンとA/Bボタンでワールド・アクションゲームを操作。ゲーム選択・RPG・パズル・工房は画面をタップ。
- 一部の小型端末では縦向き表示が小さくなります。

## ローカルで動かす（Windows）

ZIPを展開し、`main.py` があるフォルダで PowerShell を開いて：

```powershell
py -m pip install -r requirements.txt
py -m uvicorn main:app --host 127.0.0.1 --port 8000
```

ブラウザで http://127.0.0.1:8000 を開いてください。

## 既存のGitHubとRenderを更新する方法

- GitHub：`https://github.com/ryota321ryota-lang/domando-rush`
- **GitHubアップロード：`https://github.com/ryota321ryota-lang/domando-rush/upload`**
- **Renderサービス名：`domando-rush`**（既存サービスをそのまま使用）
- 公開URL：`https://domando-rush.onrender.com`

1. ZIPを展開し、`main.py` が直下にあるフォルダの中身をGitHubのアップロード画面にドラッグ。**ZIPそのものはアップロードしない**。
2. `main.py`、`requirements.txt`、`render.yaml`、`README.md`、`static/` 配下のファイルを確認する。
3. **Commit changes** を押す。
4. Renderの `domando-rush` は `main` ブランチのコミットで自動デプロイする設定のため、管理画面に新しいデプロイが発生する。
5. **Live**を確認してゲームURLを開く。旧版のキャッシュが残るときは `Ctrl + Shift + R` で再読み込み。

Renderの現在のビルド設定を変更する必要はありません：

- Build：`pip install -r requirements.txt`
- Start：`uvicorn main:app --host 0.0.0.0 --port $PORT`

## セーブデータと注意点
- データは**利用ブラウザのlocalStorage**に保存。別端末との同期はありません。
- Ver.5.0の `domando-rush-v5-luminous-atlas` のセーブを引き継ぐ設計。Ver.4.0やVer.3.0からの移行処理も旧コードと同様に残しています。
- 同じ端末でもブラウザのデータを削除するとセーブが消えることがあります。
- 公開サービスはRenderのFreeインスタンスで、アクセスが少ないと休止し、初回読み込みが遅くなることがあります。
- 通信中の課金要素はなく、ひとり用ブラウザゲームです。ソースやセーブに共有アカウント・パスワード・秘密鍵は含まれていません。
